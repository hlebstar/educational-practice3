# Мой Не Сам - Клининговая служба

## Описание проекта

Веб-приложение для оформления заявок на клининговые услуги. Пользователи могут регистрироваться, создавать заявки на уборку и отслеживать их статус. Администратор управляет всеми заявками через панель управления.

## Основные возможности

**Для пользователя:**
- Регистрация и авторизация
- Просмотр истории своих заявок
- Создание новой заявки (адрес, контактные данные, вид услуги, дата, время, тип оплаты)
- Отслеживание статуса заявки

**Для администратора:**
- Просмотр всех заявок с данными клиентов
- Изменение статуса заявки 
- Отмена заявки с указанием причины

## Установка и запуск

**1. Установите Node.js**

Скачайте с официального сайта: https://nodejs.org/

**2. Скачайте проект**

git clone https://github.com/hlebstar/modulpodgotovka.git
cd modulpodgotovka

**3. Установите зависимости**
cd api
npm install

**4. Запустите сервер**

node server.js

**5. Откройте сайт**

http://localhost:3000
